# Frontend Ciudadano y Panel Administrativo (Next.js)

Este directorio contiene la interfaz web opcional desarrollada con Next.js y Tailwind CSS.

## Instrucciones de Ejecución:

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Iniciar el servidor de desarrollo:
   ```bash
   npm run dev
   ```

El frontend se conectará automáticamente a la API de Flask en `http://localhost:5000/api`.
